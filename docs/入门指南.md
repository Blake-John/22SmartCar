## M1 ROS2 与系统集成

### 学习目标
掌握节点通信、Launch 编排、TF2 坐标变换、性能调优与分布式通信。

### 阶段一：ROS2 通信基础


**官方文档**
- **ROS2 Humble 官方 Tutorials**：https://docs.ros.org/en/humble/Tutorials.html
- **中文指南**：https://docs.ros.org/en/humble/

### 阶段二：Launch 编排

**Launch 文件**
- **ROS2 Launch 官方教程**：https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Creating-Launch-Files.html 


### 阶段三：性能调优与分布式

**性能调优**
- 工具链：`ros2 topic hz` / `ros2 topic bw` / `ros2 topic delay` （测量频率、带宽、延迟）
- 改造手段：多线程执行器 + 回调组隔离、进程内通信（Composable Nodes）、QoS 调优
- 目标：端到端延迟从秒级降到 < 200ms

**分布式通信**
- **RMW 选型**：CycloneDDS / FastDDS / Zenoh
- **故障诊断**：`ros2 node list` → `ping` → `tcpdump` → 检查 `ROS_DOMAIN_ID`、防火墙、组播配置
- **生命周期节点**：`LifecycleNode` 实现自动重启与状态恢复

在官方的文档中学习相关的通信原理与调优方式

掌握传统视觉、PnP 位姿估计、深度学习全流程、目标追踪。

### 阶段一：传统视觉管线

**OpenCV 基础**
- **官方教程**： https://docs.opencv.org/4.13.0/index.html
- **快速入门**：

    - Python: [3h精通Opencv-Pytho](https://www.bilibili.com/video/BV16K411W7x9/?share_source=copy_web&vd_source=87b5b8a31663db98672948a18855aef1)


**相机标定**
- **OpenCV 官方标定教程**：https://docs.opencv.org/4.13.0/dc/dbb/tutorial_py_calibration.html

### 阶段二：PnP 位姿估计

**ArUco 检测与位姿估计**
- **OpenCV ArUco 板检测教程**： https://docs.opencv.org/4.13.0/d5/dae/tutorial_aruco_detection.html

### 阶段三：深度学习全流程
**YOLO 入门**
- **官方文档**： https://docs.ultralytics.com/zh

**完整流程**
| 阶段 | 工具 | 产出 |
| :--- | :--- | :--- |
| 数据采集与标注 | LabelImg / CVAT | 300+ 张标注图像 + 标注规范文档 |
| 模型训练 | Ultralytics YOLOv8n | 训练曲线 + 权重文件 |
| 评估 | mAP / PR 曲线 / 混淆矩阵 | 评估报告 + 5 张失败案例归因 |
| CPU 部署 | ONNXRuntime / OpenVINO | FPS 实测 + 耗时分解（预处理/推理/后处理） |

### 阶段四：目标追踪（2 周）

**基于检测的追踪**
- 核心思路：YOLO 提供语义位置 → IOU 匹配关联相邻帧 → 卡尔曼滤波平滑
- **短时遮挡预测**：目标丢失时，用卡尔曼预测值维持追踪（最多 10 帧）
- 可视化：追踪 ID + 运动轨迹 + 方向箭头
