# M3 展示指南

> 每题按顺序展示，仿真在**你自己的电脑上**跑，考官只看屏幕和数据。
> 演示前先做三件事：`colcon build` 过一遍、Gazebo 起一次预热、把 20 次运行的原始 CSV 放在手边。

---

## M3-1 坐标系与里程计

1. 起仿真：`ros2 launch <你的包> <你的launch文件>`，让车能收 `/cmd_vel`。
2. 指给考官看：`ros2 topic hz /odom` 的频率、`ros2 topic echo /odom --once` 里的 `frame_id` 与 `child_frame_id`。
3. 跑一次 2 m 正方形闭环（录完再去考核），同时录 `/odom` 与 `/gazebo/model_states`。
4. 打开 10 次统计表，报**位置偏差均值 ± 标准差、角度偏差均值 ± 标准差**。
5. 打开轨迹对比图：两条线、等比例坐标、起点终点、闭环偏差数值。
6. 指 TF 树图，说四个变换谁发、静态还是动态，重点是 `map → odom` 在 M3-1 里**应不应该有**。

---

## M3-2 SLAM 建图

1. 打开 `.world` 文件，指长走廊有多长、回环怎么走、**你自定的难点是什么、预期会出什么问题**。
2. 起 SLAM 建图，仅检查可运行，然后放提前录好的操作录屏，但地图必须现场从 `map.pgm` 加载。
3. `ros2 run nav2_map_server map_server --ros-args -p yaml_filename:=map.yaml` 加载，在 rviz 里看。
4. 如果有对比实验（改 `resolution` 或关回环），给两张图 + 参数差。

---

## M3-3 自主导航与调优

1. **一条命令**起全栈（仿真 + 定位 + Nav2）。
2. 考官在地图上点一个目标点（>5 m、含至少一个转弯），现场跑一次，报耗时、是否到达。
3. 打开 `nav2_params.yaml` 的调参表：≥3 个参数，每个写清 默认值 → 新值 → 为什么 → 改前改后结果。
4. 翻三张证据图：全局代价地图、局部代价地图、`/cmd_vel` 或角速度曲线。
5. 保留失败的历史，讲清楚每次失败的原因。

---

## M3-4 动态障碍下的避障

1. 起仿真、发目标点，车**出发 3 秒后**用脚本注入障碍物，看避障过程。
2. 考官随机指一个位置放障碍（不是你预置的点），跑 2 次，允许现场调参。
3. 打开 20 次数据表：2 种规划器 × 10 次，四个指标（成功率 / 平均耗时 / 绕行额外路径 / 平滑度），提前跑好再考核。
4. 报调优：哪一项变好、哪一项变差，调优后重跑的 10 次数据。
5. 讲失效边界，并**现场复现一条**。

## 演示前自查

| 题 | 必须有 |
| :-- | :-- |
| M3-1 | 能 `colcon build` 的 `smart_car_description` 包、10 次原始 CSV、轨迹图、TF 树图 |
| M3-2 | 自建 `.world`、`map.pgm` + `map.yaml`、三组质量数据、建图 rosbag |
| M3-3 | 一键 launch、`nav2_params.yaml`（带注释）、3 次运行日志、三张诊断图 |
| M3-4 | 障碍注入脚本、20 次原始记录、两种规划器配置、四指标对比图 |
| 通用 | 笔记本能起 Gazebo（提前 10 分钟预热）、断网也能跑、关键过程有录屏兜底 |
