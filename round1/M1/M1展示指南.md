# M1 展示指南

> 现场按每题的顺序往下做，不要跳步。每题标了时间，超时考官会叫停。
> 演示前确认：工作空间已编译、`source install/setup.bash` 已生效。

---

## M1-1 三节点链路（3 分钟）

1. 起 A / B / C 三个节点。
2. `ros2 interface show sensor_interfaces/msg/SensorData` —— 让考官看到 4 个字段和顺序。
3. `ros2 topic hz /processed_distance` —— 稳定在 10 Hz 左右。
4. `ros2 param set /node_b_filter alpha 0.9` —— 终端上的数值要明显变"跳"。
5. 调一次 `/trigger_alarm`；再停掉服务端后触发一次 —— 出现 `[WARN] 报警服务超时`。
6. 提前准备好往 `/sensor_data` 发一条 `status = 1` 的消息，你要能解释为什么这帧不参与滤波。

---

## M1-2 Launch 编排（4 分钟）

1. 用**一条** `ros2 launch` 起 `robot1` 的三个节点。
2. 用同一个 launch 再起 `robot2`，两份参数文件各自加载。
3. 让考官查 `/robot1/node_c_alarm` 与 `/robot2/node_c_alarm` 的 `alarm_threshold`。
4. `ros2 topic list` 展示两组话题是隔离的。
5. 用一个不存在的参数文件路径启动一次，展示你的报错信息。
6. 改一组的 `alpha`，看另一组会不会被带偏。

---

## M1-3 时间与坐标（5 分钟）

1. 播 bag（带 `--clock`），起你的投影节点。
2. `ros2 run tf2_ros tf2_echo camera_link laser_link` —— 证明 TF 链通。
3. 展示 `projection_*.png`（至少 3 张）。
4. 换第二套 `extrinsics.yaml` 重跑一次，再展示一组图。
5. 指一个投影点，说出它对应的激光距离。

---

## M1-4 调优与故障记录（7 分钟）

1. 起你的优化版，报四个数：输入频率、输出频率、控制频率、端到端 P95。
2. 考官会只换掉一端（发布端或处理端），你重测并指出瓶颈在哪。
3. 打开 `FAULTS.md`，挑一条讲：命令、输出、根因、修复、验证。

---
