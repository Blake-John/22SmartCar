> **难度**：★

## 场景

你刚进车队，学长丢给你一句话：

> "装 Ubuntu 和 ROS 及相应的开发环境，速交。"

——所有故事的起点。

---

## 任务

### 1. 搭好 Ubuntu + ROS2 开发环境

在 **物理机 / WSL2 / 虚拟机**（三选一）上安装：

| 组件 | 要求 |
| :-- | :-- |
| Ubuntu | **22.04**（ROS2 Humble 官方支持版本） |
| ROS2 | **Humble** |
| Python 虚拟环境 | **uv 或 conda**（二选一，能激活） |
| C / C++ | gcc / g++ / make / cmake 可用 |
| 编辑器 | VS Code + 必要开发插件（Python、C/C++、Remote） |
| 版本控制 | Git（已配置 user.name / user.email） |

### 2. 写一份 README

简述"通过什么方法 / 查阅什么资料 / 完成什么任务"，**重点写「本机踩坑实录」**：

- 装系统时遇到什么问题，如何解决
- 报错原文是什么，你怎么定位到原因的
- 参考资料链接

### 3. 创建 Git 仓库（本地 + 云端）

- 用于存放后续**所有**代码
- 仓库结构**按模块与题目划分**：

```
22SmartCar/
├── M0/
│   ├── M0-1/          # 环境搭建：README + 踩坑记录
│   ├── M0-2/          # 首个代码工具
│   ├── M0-3/          # 代码排查
│   └── M0-4/          # Mini 项目实战
├── M1/ ...
└── README.md          # 仓库总说明
```

### 4. 学会远程登录，操控远程电脑

- 用 `ssh` 登录到**开发板 / 服务器**
- 会传文件（`scp` / `rsync`）
- 会配 SSH key（免密登录）

可以和别人共同尝试，相互登录。
