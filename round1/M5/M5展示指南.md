# M5 展示指南

> 本科目主要是**主机侧软件**，M5-3 需要车能动（实车或仿真都行）。
> 演示前先做三件事：依赖装好能离线跑、8080 与 8081 两个端口空着、练习日数据包解压到本地。

---

## M5-1 任务状态机

1. 指给考官看状态转移写在哪、节点怎么注入。
2. 跑 `pytest -q`，让考官看是不是全绿、覆盖了哪几类失败。
3. 跑你自己写的失败示例 yaml ，里面有一条 fallback 链（且 fallback 也会失败）、一个 parallel 分支（一个子任务失败）、一个会超时的节点、一个重试会耗尽的节点。一键跑完，打开 `task_report.json`。
4. 指报告里的耗时、重试次数、降级记录，说明"卡死"为什么不会发生。

---

## M5-2 监控面板

1. 一条命令启动，确认**自动开浏览器**、话题自动出现（不是手工填 IP）。
2. 跑模拟赛约 90 秒，看五个区域是否都在动：状态机、指标折线、故障流、裁判与资源、顶部控制条。
3. **故障注入**：考官任选两项——杀掉相机节点 / 发一个假高温话题 / 断 DDS。要求故障 **<1 s** 出现在故障流里，折线出现断崖，状态机节点变橙。
4. 点一次导出，确认能离线回放。

---

## M5-3 一体化终端

1. 一条命令起终端（**8081 端口**，别和 8080 的仪表盘打架），确认裁判、任务控制、热切、急停、审计都在同一个界面里，**不许开第二个终端**。
2. **完整赛制演练**：裁判发 `START` → 倒计时 → 状态机启动 → 面板同步。
3. **热切验证**：先记下感知节点 PID → 在终端点"切模型" → 确认 **PID 没变**、模型确实生效、`switch_log.csv` 有记录。
4. **故障联动**：拔相机 → 看门狗降级 → 终端告警 + 语音播报。
5. **急停演练**：让车跑起来 → 按**物理急停** → 底盘零速、**不自动恢复**、审计写 `EMERGENCY_STOP`、裁判端收到 `FAULT`。

---

## M5-4 复盘与实验管理

1. 展示单次运行复盘的结果。
2. 跑一遍实验全流程：`new → run → compare → promote`，看 `compare` 的表格与图（自己准备数据）。
3. 生成基线包，解压跑 `verify_baseline.sh`。
