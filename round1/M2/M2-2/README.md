# M2-2 ｜ 单目视觉位姿估计：从像素到 3D 空间

> **难度**：★★
> **综合考察**：相机投影模型、PnP 位姿估计、坐标系变换、多视图几何
> **本题分值**：20 分
> **题目来源**：`创意组一轮考核.md` §M2-2
> **形式**：自备相机与打印靶标；现场带代码与文档，现场实测
> **前置**：**必须使用 M2-1 标定的 `camera_calibration.yaml`**（同一台相机）

---

## 0. 这道题在考什么

把"检测到一个东西"升级为"**知道它在哪、朝向哪**"。
这是从 2D 感知跨到 3D 空间的第一步，也是机器人抓取/降落/对接的地基。

本题的成败分水岭非常清晰：

- **角点顺序错** → 位姿差 90°/180°，画面看起来"好像是好的"
- **没用畸变系数** → 近距离时位置偏差能到 10%+
- **物体系定义没想清楚** → tvec 是"相机到靶标"还是"靶标到相机"，符号反了

这三坑在结果图上**看起来都对**，只有在追问时才暴露。

## 2. 任务分解

### 2.1 靶标检测

输出**四个角点的像素坐标**，且**顺序必须正确**。

| 靶标 | 顺序约定（必须与你的物体系定义一致） |
| :-- | :-- |
| ArUco / AprilTag | 库返回的顺序：**TL → TR → BR → BL**（以码自身方向为准） |
| 棋盘格 | 行优先；**必须说明**原点取在哪个角、轴怎么指 |

**自检方法**（必做，现场会问）：

- 把靶标**顺时针转 90°**，输出的"TL"应该跟着转（还是固定在图像左上？）
  ——想清楚你的角点是**图像顺序**还是**靶标自身顺序**，两者混用必然出错。

### 2.2 物体系定义

**必须写进文档**，三要素缺一不可：

```
原点：靶标几何中心（推荐）或左上角点
X 轴：沿靶标某条边，指向哪个角
Y 轴：由 X 与 Z 正交确定（右手系）
Z 轴：垂直码面，指向相机 还是 背离相机（必须写明！）
```

> `cv2.solvePnP` 的约定：**Z 从靶标指向相机一侧为正**（相机在 +Z）。
> 画坐标轴时 Z 朝向相机，看起来"箭头戳向自己"——这是**正常**的，
> 很多人以为是 bug 去改符号，反而改错了。

### 2.3 PnP 解算（核心）

| 步骤 | 要求 |
| :-- | :-- |
| 3D-2D 对应 | 物体系角点（米）↔ 图像角点（像素），**数量 ≥4** |
| 求解 | `cv2.solvePnP`，说明你选的 flag：`SOLVEPNP_IPPE`(平面靶标推荐) / `ITERATIVE` / `SOLVEPNP_SQPNP`，**以及为什么** |
| 精化 | 建议加 `cv2.solvePnPRefineLM`（亚像素角点 + LM 迭代），并说明对结果的影响 |
| 换算 | rvec → 旋转矩阵 → 欧拉角 (roll/pitch/yaw)，**写清你用的旋转顺序**（如 XYZ 内旋） |

**必须回答**（文档 + 追问）：

- 为什么平面靶标**只用 4 个点**也能解出 6-DoF？有没有多解风险？
- `IPPE` 为什么会输出两个解？怎么选正确的那个？（提示：重投影误差）
- 距离越远误差越大，**为什么**？（角点像素误差 × 投影逆变换的放大率）

### 2.4 可视化

| 项 | 要求 |
| :-- | :-- |
| 坐标轴 | `cv2.drawFrameAxes`（或手画），X 红 / Y 绿 / Z 蓝，长度约靶标边长的 0.5~1 倍 |
| 信息叠显 | `[距离: 1.23m, 偏航: +15.2°, 俯仰: -3.1°]` 格式，数值实时刷新 |
| 实时性 | 摄像头/视频流下 ≥15 FPS（2020 年后的笔记本均可） |

### 2.5 精度实测

**用尺子量，别只看数字自己觉得对**。

| 实验 | 做法 | 记录 |
| :-- | :-- | :-- |
| 距离线性度 | 靶标固定，相机在 0.3 / 0.5 / 0.8 / 1.2 m 各测 5 次 | 每档 z 均值 ± 标准差，与实测距离的**绝对误差** |
| 姿态响应 | 靶标绕某轴转 ~30°/60°/90° | 输出角与实际角的偏差 |
| 畸变的影响 | 同一帧，分别用**带畸变**与**不带畸变**解 PnP | 两套结果的差（这一项最能暴露"没理解畸变"） |

> 现场会拿尺子/卷尺核对你的 z 值。**偏差 >5% 要能说出原因**。

## 3. 现场流程（约 15 分钟）

| 环节 | 内容 | 时间 |
| :-- | :-- | :--: |
| 内参检查 | 确认 yaml 是 M2-1 那份、分辨率一致 | 2 min |
| 实时演示 | 摄像头 + 自带靶标，看角点/坐标轴/数值叠显 | 4 min |
| 精度核对 | 现场量距离，对比你的输出 | 4 min |
| 追问 | 角点顺序、物体系、IPPE 双解、畸变影响 | 5 min |

> **靶标自带**（现场不给靶标——尺寸必须是你自己用尺量过的那一个，否则物体系不成立）。
> 现场提供**卷尺**用于核对距离。靶标**必须贴平**（贴硬纸板，别拿软纸）。
