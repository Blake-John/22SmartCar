# M2 展示指南

> 每题按顺序往下做，不要跳步。M2 不提供任何数据：视频、标注、靶标、演示视频**都要自己准备**；现场不摆任何实物。
> 演示前确认：依赖装好、模型和权重在本地、摄像头能被 `cv2.VideoCapture` 打开。

---

## M2-1 传统视觉管线（5 分钟）

1. 报数据规模：几段、每段多长、白天/夜间/逆光怎么分的、**哪一段是测试段**。
2. 当场跑 `eval.py`，念测试段那一行：状态准确率、中心误差 P50 / P95、漏检率、误检率。
3. 翻混淆矩阵与分段表，讲测试段和调参段差在哪。
4. 打开一段的标注图，指最小外接圆、中心坐标、面积。
5. 从测试段随机指一帧，现场跑 `detect.py` 与标注对照；问某条阈值是怎么定下来的。

---

## M2-2 单目位姿估计（4 分钟）

1. 报靶标边长（mm）和内参从哪来，打开配置文件指给考官看。
2. 自带靶标放桌上不动或者准备一段视频，连跑几秒：四角点、X/Y/Z 三色坐标轴、距离/偏航/俯仰叠显，数值应当稳定。
3. 翻精度表：0.3 / 0.5 / 0.8 / 1.2 m 四档 `z` 误差与标准差、姿态 30/60/90°、带畸变 vs 不带。
4. 讲 `IPPE` 双解怎么选，为什么不带畸变在近距离最差。
5. 指定一个边长（比如 80 mm）让你改配置重跑，看输出是否按比例变化。

---

## M2-3 深度学习全流程（9 分钟）

1. 打开类别分布图与划分说明，讲清"同一背景的连拍没有跨 train/test"。
2. 打开 loss 曲线与一键训练命令，报 epoch 数、增强方式。
3. 报指标：mAP@0.5、mAP@0.5:0.95、各类 P/R/F1、混淆矩阵。
4. 跑 PyTorch vs ONNX 同批图对比，报 `max|Δbox|`、`max|Δconf|`。
5. 播放自备的演示视频（≥30 s，含遮挡段），看框、类别、置信度、FPS；遮挡那 1~2 秒框应该消失或转预测，不能乱跳。

---

## M2-4 目标追踪与运动预测（8 分钟）

1. 播你自带的视频（≥30 秒），展示 ID、轨迹、`PREDICTED` 虚线框。
2. 视频留有遮挡的片段，看 ID 是否保持、框是否变虚线、之后是否恢复。
3. 放「出画再入」片段，说明 ID 没有被新目标顶掉。
4. 打开对比表：纯 IoU vs 卡尔曼 的 ID 切换次数、遮挡恢复率、静止目标抖动。
5. 报 R 的实测方法（哪段数据、算出多大方差）和 Q 的量级依据。
