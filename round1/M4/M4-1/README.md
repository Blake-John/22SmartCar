# M4-1 ｜ 点亮板子：把最小系统跑通

> **难度**：★
> **综合考察**：单片机工程流程、GPIO、串口、技术写作
> **本题分值权重**：10
> **题目来源**：`创意组一轮考核.md` §M4-1
> **形式**：自备开发板；现场带工程与文档，**考官会换一块改了引脚的板子**实测

---

## 0. 这道题在考什么

嵌入式最基础也最容易翻车的一步：**从空目录到一个能跑起来的工程**。

考三件事：

1. 你**认不认识**手上这块板（主控型号、晶振、下载口、LED/按键接在哪）
2. 你能不能**不靠别人的工程模板**自己搭出来（工具链、时钟、外设初始化）
3. 你的代码**是否可移植**——换了引脚能不能 10 分钟内改好

> 第 3 条是本题的**现场考点**：考官会给你一块**同款但改了 LED/按键引脚**的板子。
> 如果你的引脚定义散落在代码各处、或写死在中断向量里，现场就会超时。

## 1. 硬性要求

| # | 要求 | 说明 |
| :-- | :-- | :-- |
| 1 | **从空目录建工程** | 不允许直接交厂商例程/开发板配套工程；可以用官方 HAL/寄存器库 |
| 2 | **能编译、能烧录** | 提供一键脚本或明确步骤；工程可重现构建 |
| 3 | **功能 A：按键控 LED** | 按下亮、松开灭（或翻转，二选一但要在文档写清） |
| 4 | **功能 B：串口心跳** | **115200 8N1**，每 **500ms** 打印一次心跳；按键按下时**额外**打印事件 |
| 5 | **引脚定义集中** | 引脚号/端口必须**只在一处定义**（宏或配置表），便于现场改板 |
| 6 | **文档含接线照片** | `board_notes.md` + 实物照片（能看清引脚与丝印） |

> **建议主控**：STM32F103C8T6（便宜耐造）。也可用你手上任何 MCU，
> 但必须满足"能从空目录建工程"这个前提（Arduino 的 `setup/loop` 隐藏了太多细节，
> 用它可以，但要在文档里说清时钟与寄存器层面的配置）。

## 2. 任务分解

### 2.1 识别板上资源

写 `board_notes.md`，必须包含：

| 项 | 内容 |
| :-- | :-- |
| 主控型号 | 完整型号（如 STM32F103C8T6），Flash/RAM 大小 |
| 晶振 | 外部晶振频率（常见 8MHz），系统主频被你配到多少 |
| 下载口 | SWD / JTAG / 串口 ISP；你用哪个、接线是哪几根 |
| LED | 接在哪个端口哪一位、**高电平亮还是低电平亮** |
| 按键 | 接在哪个端口哪一位、**按下是接地还是接 VCC**（决定上拉/下拉） |
| 串口 | 用哪个 USART、TX/RX 引脚、波特率 |

> **怎么查**：看丝印 + 万用表量通断 + 查原理图。**不许靠猜**。
> 如果板子没有原理图，就去量：LED 的正极接哪、限流电阻多大。

### 2.2 搭工程

| 步骤 | 要求 |
| :-- | :-- |
| 工具链 | 自选（Keil / STM32CubeIDE / PlatformIO / Makefile+arm-none-eabi-gcc 均可） |
| 启动 | 从空目录开始：启动文件、链接脚本、时钟配置都自己过一遍 |
| 外设 | 至少配 GPIO（LED + 按键）与 USART |
| 按键 | **必须做消抖**（硬件 RC 或软件延时/状态机），并说明你选了哪种 |
| 构建 | 提供一键命令（如 `make` 或构建脚本），**读 README 能复现** |

**文档要回答**：

- 系统主频怎么算出来的？（HSE × PLL 倍频 ÷ 分频）
- 串口波特率的分频系数是多少？误差多少？（`USARTDIV` 计算过程）
- 按键消抖你放在哪一层？（中断里？主循环里？）为什么？

### 2.3 功能 A：按键控 LED

- 按一下亮、再按一下灭（**或**按住亮松开灭，自选）
- **必须在文档里写清你用的是哪种**（否则现场无法判断"对不对"）

**进阶（可选，但现场会问）**：

- 你用**轮询**还是**中断**检测按键？为什么？
- 如果用中断：有没有考虑**机械抖动导致多次触发**？怎么处理？

### 2.4 功能 B：串口心跳与事件

| 输出 | 内容 | 频率 |
| :-- | :-- | :-- |
| 心跳 | 一行文本（建议含计数器/时间戳） | 每 500ms |
| 事件 | 按键按下时额外打印一行 | 事件触发 |

**要求**：

- 波特率 **115200**，8 数据位、无校验、1 停止位（8N1）
- **不许用阻塞式 `delay` 卡住主循环**（否则心跳间隔会漂）
  ——建议用定时器中断或 `HAL_GetTick()` 比较
- 心跳**间隔要准**：现场会掐表或用串口时间戳验证，漂移 >10% 要解释

**示波器/串口助手截图**：贴一张能看到心跳间隔的截图。

### 2.5 现场换板演练（本题关键）

考官会给你一块**同款但改了 LED/按键引脚**的板子。要求：

- **10 分钟内**改完引脚定义、重新编译、烧录、跑通两个功能
- 只许改**引脚定义那一处**（如果做不到，说明你的工程结构有问题）

**提前自测**：把你自己的引脚定义改一个口（如 PB0 → PB1），看要改几个文件、几行。
**超过 3 处的，先去重构**。

## 3. 现场流程

**第一段：常规验收（约 10 分钟）**

| 环节 | 内容 | 时间 |
| :-- | :-- | :--: |
| 看文档 | `board_notes.md` 是否与实物一致（抽一项当场量） | 2 min |
| 跑原板 | 烧录原工程，验两个功能 + 心跳间隔 | 3 min |
| 追问 | 时钟/波特率计算、消抖位置、为何这么分层 | 5 min |

**第二段：换板演练（独立计时，限 10 分钟）**

考官发一块**同款但改了 LED/按键引脚**的板子，要求：

- 只改**引脚定义那一处**（`board_config.h`），重新编译、烧录、跑通两个功能
- **超时未跑通**，视为代码不可移植
- 考官可能**临时再改一处**你做过的引脚，确认不是提前准备了第二套代码

> 这一段**独立于上面的 10 分钟**，单独计时。

## 4. 交付物与格式

```
M4-1/
├── board_notes.md           # 板上资源识别（含引脚表）
├── src/                     # 工程源码
│   ├── main.c
│   ├── board_config.h       # ★ 引脚定义集中在这里（现场只改这个文件）
│   └── ...
├── build/                   # 构建脚本（Makefile / CMakeLists / 一键脚本）
├── docs/
│   ├── photos/              # 接线照片（能看清丝印与引脚）
│   └── serial_log.txt       # 串口输出原文（含心跳与按键事件）
└── README.md                # 从空目录到跑通的完整步骤
```

### `board_config.h` 建议结构（现场可移植的关键）

```c
/* 所有引脚定义集中在此；换板只改这里 */
#define LED_PORT        GPIOB
#define LED_PIN         GPIO_PIN_0
#define LED_ACTIVE_HIGH 1        /* 1=高电平亮, 0=低电平亮 */

#define KEY_PORT        GPIOA
#define KEY_PIN         GPIO_PIN_0
#define KEY_ACTIVE_LOW  1        /* 1=按下接地 */

#define UART_BAUD       115200
#define HEARTBEAT_MS    500
```

### 构建约定

```bash
# 提供一键构建（示例）
make            # 或 ./build.sh 或 pio run
make flash      # 烧录（说明用的什么下载器）
```

命令名可自定，但 README 里要写明**从零到跑通**的每一步。

## 5. 明确禁止

- 禁止直接交厂商例程改几个宏（要能说清启动流程与时钟配置）
- 禁止把引脚号散落在多个文件（现场换板会超时）
- 禁止用阻塞 `delay` 实现 500ms 心跳（间隔会漂，且按键响应变差）
- 禁止不做按键消抖（现场会连续按，抖动会暴露）
- 禁止文档里的引脚与实物不符（现场会量）
- 禁止只贴代码不贴串口输出原文（无法证明心跳间隔）
