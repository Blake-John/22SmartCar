# M4-3 ｜ 让它走直线不抽搐：速度环整定

> **难度**：★★★
> **综合考察**：电机驱动、PID 闭环、示波器整定、抗扰实验
> **本题分值权重**：30
> **题目来源**：`创意组一轮考核.md` §M4-3
> **形式**：自备电机 + 编码器 + 驱动；现场带代码与曲线，**考官会下发变速目标序列**实测

---

## 0. 这道题在考什么

从"电机能转"到"电机**听话**"。

考察核心不是"PID 公式背得对不对"，而是：

1. 你会不会**用曲线说话**（超调、稳态误差、恢复时间都是**量出来的**）
2. 你懂不懂 **P / PI / PID 各自的取舍**（不是"三个一起上最好"）
3. 你能不能**扛住扰动**（手捏停轮子再放开，看谁的恢复更体面）

> 现场考点：考官下发一段**你没见过的变速目标序列**（如 20 → 60 → 30 → 0 r/min 阶梯），
> 闭环要**跟得住**且**不超调失控**。这检验你的参数是"针对某个转速调出来的"
> 还是"真的有一套可用的控制律"。

## 1. 硬性要求

| # | 要求 | 说明 |
| :-- | :-- | :-- |
| 1 | **闭环平台** | 直流减速电机 + 编码器 + 驱动（TB6612 / L298N / 其他） |
| 2 | **控制周期 10ms** | 必须是**定时器中断或严格周期任务**，不许 `delay` 凑 |
| 3 | **PID 速度环** | 位置式 **或** 增量式，说明你选哪个、为什么 |
| 4 | **三组对比** | **P / PI / PID** 各跑一次阶跃，导出曲线 |
| 5 | **抗扰实验** | 运行中**手捏停轮子再放开**，三组各做一次 |
| 6 | **量化指标** | 每组都要给：超调量、上升时间、稳态误差、恢复时间 |
| 7 | **积分限幅** | 必须做**抗积分饱和**（否则现场阶梯下降时会失控） |

> **第 7 条是隐藏考点**：目标从 60 突然降到 0 时，
> 没有抗积分饱和的控制器会因为积分项累积而**反向冲过头**，现场一眼看出来。

## 2. 任务分解

### 2.1 搭建闭环平台

| 组件 | 要求 |
| :-- | :-- |
| 电机 | 直流减速电机（带编码器），记录**减速比**与**额定电压** |
| 驱动 | TB6612 或 L298N；说明**PWM 频率**选了多高、为什么 |
| 编码器 | 与 M4-2 同一套测速代码（可复用） |
| 供电 | 电机电源与逻辑电源**是否隔离**？共地了吗？ |

**必须回答**：

- **PWM 频率**选了多少？太低会怎样（啸叫、电流纹波）？太高会怎样（驱动发热）？
- 你的**测速更新率**与控制周期（10ms）是什么关系？
  如果测速慢于控制，会引入什么？（提示：延迟 → 相位滞后 → 振荡）

### 2.2 实现 PID 速度环

**位置式**：

```
u = Kp*e + Ki*∫e dt + Kd*de/dt
```

**增量式**：

```
Δu = Kp*(e_k - e_{k-1}) + Ki*e_k + Kd*(e_k - 2e_{k-1} + e_{k-2})
```

**必须实现**：

| 项 | 要求 |
| :-- | :-- |
| 输出限幅 | PWM 有物理上限，必须限 |
| **积分限幅 / 抗饱和** | 防止积分项无限累积（**关键**） |
| 微分处理 | 原始微分对噪声极敏感，说明你用没用**低通/不完全微分** |
| 单位 | 目标与反馈都用 **r/min**（或都用编码器计数），**不要混** |

**必须回答**：

- 位置式与增量式的**本质区别**是什么？哪种更适合带积分的场合？
- 你的 `dt` 实际是多少？**真的是 10ms 吗**？（用示波器或计时器验证，别假设）

### 2.3 阶跃整定（三组对比）

对**同一目标转速**（建议 60 r/min）分别跑：

| 组 | 参数 | 记录什么 |
| :-- | :-- | :-- |
| ① 纯 P | `Kp>0, Ki=0, Kd=0` | 有稳态误差吗？为什么 |
| ② PI | `Kp, Ki>0, Kd=0` | 稳态误差消了吗？超调变大吗 |
| ③ PID | `Kp, Ki, Kd>0` | 超调压下去了吗？对噪声敏感吗 |

**每组导出曲线**（串口示波器），并填表：

| 组 | 超调量 (%) | 上升时间 (ms) | 稳态误差 (r/min) | 稳态波动 (±r/min) |
| :--: | :--: | :--: | :--: | :--: |
| P | | | | |
| PI | | | | |
| PID | | | | |

**必须回答**：

- **纯 P 为什么会有稳态误差**？（从公式推，不是背结论）
- 加了 I 之后**超调变大**，怎么压？（提示：减小 Ki、加 D、或做积分分离）
- **D 项对噪声敏感**，你的曲线里有体现吗？

### 2.4 抗扰实验

**做法**：让电机稳定运行在 60 r/min，然后：

1. **用手捏停轮子**（保持 1~2 秒）
2. **松开**

**三组参数各做一次**，对比：

| 组 | 捏停时 PWM 是否顶到上限 | 松开后恢复到目标的时间 | 是否过冲 |
| :--: | :--: | :--: | :--: |
| P | | | |
| PI | | | |
| PID | | | |

**必须回答**：

- 捏停期间**积分项在做什么**？（这是抗饱和的关键场景）
- 如果你的控制器**没有抗饱和**，松开后会怎样？（描述现象，最好有对比曲线）
- 三种参数下，**"跟得紧"与"抗扰好"是否矛盾**？

### 2.5 现场变速序列（本题关键）

考官会下发一段**你没见过的**目标序列，例如：

```
20 r/min → 60 r/min → 30 r/min → 0 r/min
每段保持若干秒
```

**达标要求**：

- 每段**跟得住**（稳态误差在可接受范围，如 ±5 r/min）
- **不超调失控**（不允许出现反向冲或持续振荡）
- 段间切换**恢复时间**要合理（给出你的数据）

**提前自测**：自己造几组不同的阶梯序列（含**下降沿**），
看你的参数在下降时是否会因为积分饱和而冲过头。

## 3. 现场流程（约 18 分钟）

| 环节 | 内容 | 时间 |
| :-- | :-- | :--: |
| 平台检查 | 看接线、确认控制周期真的 10ms | 3 min |
| 三组曲线 | 看 P/PI/PID 的阶跃响应与量化指标表 | 4 min |
| 抗扰演示 | **现场捏停再放开**，看恢复过程 | 4 min |
| **变速序列** | 考官下发目标序列，闭环跟住 | 5 min |
| 追问 | 抗饱和、D 项噪声、稳态误差来源 | 2 min |

> 现场可以**调参**（这是整定的一部分），但要说明每次改动的依据。

- `t`：秒
- `target_rpm` / `actual_rpm`：目标与实测转速

- 依赖尽量少（numpy 即可）

## 5. 明确禁止

- 禁止用 `delay` 凑控制周期（必须定时器/严格周期，现场会验证）
- 禁止不做**积分限幅**（阶梯下降时会失控，现场必现）
- 禁止把三种参数只调"能转就行"而不给量化指标
- 禁止只贴好看的曲线不贴原始 CSV
- 禁止目标与反馈单位混用（r/min 与编码器计数混算会差一个系数）
- 禁止抗扰实验只做一次就下结论（至少三组各一次，且要说明是否可重复）
- 禁止把参数写死在中断里无法在线调整（现场要能调参）
